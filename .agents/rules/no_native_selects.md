# Project Rule: Custom UI Controls (No Native Browser Selects)

- NEVER use native browser `<select>` elements in this project.
- Always use custom select components (`custom-select-container`, `custom-select-trigger`, `custom-select-options`) with custom HTML/CSS/JS styling matching the web application design system.
- Never use emojis in UI text, options, or messages. Use Google Material Symbols icons (`<span class="material-symbols-outlined">...</span>`).
